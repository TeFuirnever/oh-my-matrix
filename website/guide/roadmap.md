# Roadmap

## P0: Public Truth Alignment

README, website, architecture docs, and visual assets must represent all first-class modules: Autopilot, Dynamic Workflows, and Permission Policy.

## P1: Host Deploy Runbook

Document the real build, pack/copy, host refresh, gateway restart, and deployed-dist smoke path. Source tests are not enough.

## P2: Autopilot Release Readiness

Clarify public package policy, `WORKFLOW.md` examples, projection contract, and evidence gate examples.

## P3: Dynamic Workflows Observability

Define workflow graph, branch state, blocked-call reporting, and final synthesis UI contracts.

## P4: Permission Policy Hardening

Move beyond tokenize-based shell handling for redirect writes and quote-aware operator splitting.

Full details live in [`docs/roadmap.md`](https://github.com/TeFuirnever/oh-my-matrix/blob/master/docs/roadmap.md).
